# Prompt Engineering

## Prompt Governance

Prompts that affect HR decisions, payroll, compliance, employee communication, or automated workflows must be versioned, reviewed, tested, and audited.

## Prompt Template Requirements

- Purpose
- Inputs
- Output schema
- Safety constraints
- Role and permission assumptions
- Examples
- Evaluation cases
- Version history

## Quality Rules

- Prefer structured outputs for downstream automation.
- Include explicit refusal and escalation criteria.
- Avoid embedding business rules only in prompts; canonical rules belong in application code and documentation.
