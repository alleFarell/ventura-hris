# Feature Development Workflow

## Required Order

1. Business requirement
2. Functional requirement
3. Non-functional requirement
4. Business rules
5. Database design
6. ERD
7. API design
8. Frontend flow
9. Sequence diagram
10. Acceptance criteria
11. Architecture review
12. Implementation
13. Testing
14. Release review

## Approval Gate

Implementation must not begin until the feature package is complete enough for review.

## Definition of Ready

A feature is ready for implementation when scope, roles, permissions, rules, data model, API contract, UI flow, and test expectations are documented.

## Definition of Done

A feature is done when implementation, tests, docs, migrations, OpenAPI, audit behavior, permissions, and release notes are complete.
