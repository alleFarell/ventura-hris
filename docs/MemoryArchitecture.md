# Memory Architecture

## Purpose

Memory supports continuity for AI assistants while respecting privacy, permissions, retention, and audit requirements.

## Memory Types

- Conversation history
- User preference memory
- Task memory
- Organizational knowledge memory
- Feature-specific operational memory

## Rules

- Memory must be permission-aware.
- Sensitive employee data must have retention controls.
- Users must be able to understand what memory influenced an AI response.
- Business records must not rely on unreviewed conversational memory as the source of truth.
