# Agent Architecture

## Purpose

AI agents automate bounded HR workflows through tools, policies, permissions, and human approvals.

## Agent Capabilities

- HR chatbot
- Policy Q&A
- Resume screening
- Payroll assistant
- Leave assistant
- Attendance analysis
- Performance review assistant
- Goal recommendation
- Training recommendation
- HR report generation
- Document generation
- Natural language database query

## Control Model

Agents must operate through:

- Explicit tool definitions
- RBAC checks
- Workflow state
- Human approval for high-risk actions
- Audit logs
- Prompt and model version traceability
