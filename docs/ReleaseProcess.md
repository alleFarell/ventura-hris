# Release Process

## Release Stages

1. Scope confirmation
2. Documentation review
3. Migration review
4. Security review
5. Test execution
6. Staging deployment
7. Business validation
8. Production deployment
9. Post-release monitoring

## Versioning

Use semantic versioning once public releases begin.

## Release Notes

Release notes must include user-facing changes, technical changes, database changes, API changes, known issues, and rollback notes.
