# Attendance API

## Candidate Endpoints

- POST /api/v1/attendance/clock-in
- POST /api/v1/attendance/clock-out
- GET /api/v1/attendance-summaries
- POST /api/v1/leave-requests
- POST /api/v1/overtime-requests

## Requirements

Endpoints must define request schemas, response schemas, errors, pagination or filtering where applicable, permissions, audit behavior, and OpenAPI documentation.
