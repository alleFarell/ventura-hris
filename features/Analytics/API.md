# Analytics API

## Candidate Endpoints

- GET /api/v1/dashboards
- GET /api/v1/reports
- POST /api/v1/reports/{id}/exports
- GET /api/v1/analytics/metrics
- POST /api/v1/analytics/nlq

## Requirements

Endpoints must define request schemas, response schemas, errors, pagination or filtering where applicable, permissions, audit behavior, and OpenAPI documentation.
