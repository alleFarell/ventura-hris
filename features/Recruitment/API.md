# Recruitment API

## Candidate Endpoints

- GET /api/v1/job-vacancies
- POST /api/v1/job-vacancies
- GET /api/v1/candidates
- POST /api/v1/candidates
- POST /api/v1/interviews

## Requirements

Endpoints must define request schemas, response schemas, errors, pagination or filtering where applicable, permissions, audit behavior, and OpenAPI documentation.
