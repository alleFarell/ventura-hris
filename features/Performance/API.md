# Performance API

## Candidate Endpoints

- GET /api/v1/performance-cycles
- POST /api/v1/goals
- GET /api/v1/appraisals
- POST /api/v1/appraisals/{id}/submit
- POST /api/v1/feedback

## Requirements

Endpoints must define request schemas, response schemas, errors, pagination or filtering where applicable, permissions, audit behavior, and OpenAPI documentation.
