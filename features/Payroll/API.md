# Payroll API

## Candidate Endpoints

- GET /api/v1/payroll-periods
- POST /api/v1/payroll-periods
- POST /api/v1/payroll-runs
- GET /api/v1/payslips
- GET /api/v1/payslips/{id}

## Requirements

Endpoints must define request schemas, response schemas, errors, pagination or filtering where applicable, permissions, audit behavior, and OpenAPI documentation.
