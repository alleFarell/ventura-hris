# Features

This folder contains documentation-first feature packages.

Each feature folder must include:

- Feature.md
- Database.md
- API.md
- Frontend.md
- BusinessRules.md
- SequenceDiagram.md
- FutureEnhancement.md

Implementation must not begin until these documents are complete and reviewed.

## Initial Feature Domains

- Setup
- Organization
- Employee
- Attendance
- Payroll
- Recruitment
- Performance
- Training
- Assets
- Workflow
- Analytics
- Settings

Submodules listed in the main project prompt must be mapped into one of these domains before implementation.
