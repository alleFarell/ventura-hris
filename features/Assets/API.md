# Assets API

## Candidate Endpoints

- GET /api/v1/assets
- POST /api/v1/assets
- POST /api/v1/asset-assignments
- POST /api/v1/asset-returns
- GET /api/v1/employees/{id}/assets

## Requirements

Endpoints must define request schemas, response schemas, errors, pagination or filtering where applicable, permissions, audit behavior, and OpenAPI documentation.
