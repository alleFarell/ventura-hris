# Workflow API

## Candidate Endpoints

- GET /api/v1/tasks
- POST /api/v1/approval-requests
- POST /api/v1/approval-requests/{id}/approve
- POST /api/v1/approval-requests/{id}/reject
- GET /api/v1/notifications

## Requirements

Endpoints must define request schemas, response schemas, errors, pagination or filtering where applicable, permissions, audit behavior, and OpenAPI documentation.
