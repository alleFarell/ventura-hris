# Memory Skill

## Purpose

Guide AI memory design.

## Guidelines

- Read docs/MemoryArchitecture.md before adding memory features.
- Make memory permission-aware, auditable, and explainable.

## Do

- Define retention, source, user visibility, and deletion behavior.

## Don't

- Store sensitive employee data in memory without explicit policy.

## Examples

- Store user preference memory separately from HR business records.

## Checklist

- [ ] Permission model defined
- [ ] Retention defined
- [ ] Audit behavior defined
- [ ] User visibility reviewed
