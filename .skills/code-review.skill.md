# Code Review Skill

## Purpose

Guide review of documentation, architecture, and implementation.

## Guidelines

- Prioritize bugs, regressions, missing tests, security gaps, data integrity, and maintainability risks.
- Review docs and architecture before implementation code.

## Do

- Cite exact files and lines when reviewing code.
- Order findings by severity.

## Don't

- Lead with praise before risks.
- Block on personal style where standards are satisfied.

## Examples

- Flag payroll rounding rules that are implemented but not documented or tested.

## Checklist

- [ ] Security reviewed
- [ ] Data integrity reviewed
- [ ] Tests reviewed
- [ ] Docs reviewed
