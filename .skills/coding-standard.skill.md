# Coding Standard Skill

## Purpose

Guide code quality across the repository.

## Guidelines

- Follow `docs/CodingStandard.md`.
- Prefer clear, testable, typed, reusable code.

## Do

- Keep changes scoped.
- Follow existing patterns once implementation begins.

## Don't

- Add abstractions without real complexity to remove.
- Leave duplicated business rules.

## Examples

- Extract a payroll calculation policy when multiple workflows need the same formula.

## Checklist

- [ ] Code readable
- [ ] Naming consistent
- [ ] Duplication avoided
- [ ] Tests aligned with risk
