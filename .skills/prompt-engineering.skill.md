# Prompt Engineering Skill

## Purpose

Guide prompt design, review, and testing.

## Guidelines

- Follow `docs/PromptEngineering.md`.
- Version prompts that affect users, employees, payroll, compliance, or workflows.

## Do

- Define inputs, output schema, constraints, examples, and evaluations.
- Keep business rules in code and docs.

## Don't

- Treat prompt wording as an invisible production dependency.
- Skip tests for high-impact prompts.

## Examples

- Resume screening prompts must include evaluation cases and human-review language.

## Checklist

- [ ] Purpose stated
- [ ] Output schema defined
- [ ] Version tracked
- [ ] Evaluation included
