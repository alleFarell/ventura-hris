# Git Skill

## Purpose

Guide source control hygiene.

## Guidelines

- Use short-lived branches and pull requests.
- Follow `docs/BranchingStrategy.md`.

## Do

- Keep commits focused.
- Include docs and tests with behavior changes.

## Don't

- Mix unrelated refactors into feature work.
- Rewrite shared history without explicit approval.

## Examples

- `feature/attendance-clock-in`
- `docs/api-standard-pagination`

## Checklist

- [ ] Branch named clearly
- [ ] Change scoped
- [ ] Docs updated
- [ ] Tests included
