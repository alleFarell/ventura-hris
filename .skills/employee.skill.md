# Employee Skill

## Purpose

Guide employee master data and employment lifecycle features.

## Guidelines

- Treat employee records as the foundation for organization, attendance, payroll, assets, and performance modules.

## Do

- Separate personal, employment, family, education, experience, emergency contact, document, and contract data.
- Track history for sensitive changes.

## Don't

- Duplicate employee attributes across modules.
- Expose sensitive fields without permission checks.

## Examples

- Employment status changes should create a history record.

## Checklist

- [ ] Data ownership defined
- [ ] History requirements checked
- [ ] Permissions mapped
- [ ] Downstream impact reviewed
