# Feature Development Skill

## Purpose

Guide the required feature lifecycle.

## Guidelines

- Follow `docs/FeatureDevelopmentWorkflow.md`.
- Complete feature docs before implementation.

## Do

- Create business requirements, database design, API design, frontend flow, sequence diagram, acceptance criteria, and future enhancements.

## Don't

- Start coding from an idea alone.
- Skip architecture review for cross-module features.

## Examples

- Payroll period close requires docs for rules, approvals, accounting impact, and audit events.

## Checklist

- [ ] Requirements complete
- [ ] Database designed
- [ ] API designed
- [ ] Frontend flow designed
- [ ] Review complete
