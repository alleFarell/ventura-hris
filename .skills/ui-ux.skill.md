# UI UX Skill

## Purpose

Guide enterprise HRIS user experience.

## Guidelines

- Design for HR admins, managers, employees, recruiters, payroll teams, and system administrators.
- Favor efficient operational workflows over decorative pages.

## Do

- Define roles, states, permissions, validation, empty states, and error states.
- Keep dense data screens scannable.

## Don't

- Build marketing-style pages for internal workflows.
- Hide critical status or approval context.

## Examples

- Attendance corrections should show original punch, requested change, approver, and audit state.

## Checklist

- [ ] Roles mapped
- [ ] Workflow documented
- [ ] Edge states covered
- [ ] Accessibility considered
