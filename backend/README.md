# Backend

This folder contains the Spring Boot backend application.

## Purpose

Provide a secure, modular, enterprise-grade REST API for Ventura HRIS using Java, Spring Boot, JPA, JWT authentication, OpenAPI documentation, and database migrations.

## Required Architecture

Each backend module must follow the same layer structure:

- `controller`
- `service`
- `repository`
- `specification`
- `dto`
- `entity`
- `mapper`
- `validator`
- `exception`
- `configuration`
- `utility`
- `common`
- `security`
- `audit`
- `logging`

## Implementation Rule

Do not add backend source code for a feature until its feature documentation, database design, API design, frontend flow, and architecture review are complete.
