# Frontend

This folder contains the Next.js, React, TypeScript, Tailwind, shadcn/ui, React Query, Axios, and Zustand frontend application.

## Purpose

Provide a maintainable feature-based HRIS user experience for HR admins, managers, employees, recruiters, payroll users, and system administrators.

## Required Structure

Each feature should contain:

- `pages`
- `components`
- `hooks`
- `services`
- `types`
- `validation`
- `utils`

## UX Rule

Frontend work must start from documented user roles, workflows, states, permissions, validation rules, and acceptance criteria.
