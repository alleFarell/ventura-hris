# Audit Strategy

## Purpose

Auditability is mandatory for HR, payroll, security, workflow, and AI-assisted actions.

## Audit Event Fields

- Actor
- Action
- Target type
- Target id
- Timestamp
- Result
- Source channel
- Correlation id
- Before and after values where appropriate

## Sensitive Areas

Payroll, employee personal data, permissions, approval actions, authentication, AI tool calls, and document access require explicit audit design.
